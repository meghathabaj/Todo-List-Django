# To-Do List Management System

A web-based **To-Do List Management System** developed using Python, Django, HTML, CSS, and SQLite. This application helps users organize and manage their daily tasks efficiently.

## Features

- **Add Tasks:** Create tasks with a title and description.
- **View & Update:** Display and edit existing tasks.
- **Complete Tasks:** Move finished tasks to the Completed section.
- **Delete Tasks:** Move unwanted tasks to Trash.
- **Restore Tasks:** Recover tasks from Completed or Trash.
- **Permanent Delete:** Remove tasks permanently from Trash.
- **Bulk Actions:** Complete, delete, or restore multiple tasks at once.

## Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python, Django
- **Database:** SQLite
- **Tools:** VS Code

## How to Run

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Apply migrations: `python manage.py migrate`
4. Start the server: `python manage.py runserver`
5. Open `http://127.0.0.1:8000/`
